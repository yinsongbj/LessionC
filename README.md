# C语言极简开发入门 · 教案（Web 版）

用 HTML + CSS + JS 实现的课件，替代 PPTX。**双击 `index.html` 即可上课**，无需联网、无需 Office、无需任何构建步骤。

---

## 一、快速开始

```
c-course/web/
├── index.html              ← 双击这个
├── assets/css/theme.css
├── assets/js/content.js    全部内容（19 页正文 + 3 附录）
├── assets/js/app.js        渲染引擎与交互
└── DESIGN.md               设计说明
```

| 需求 | 做法 |
| :- | :- |
| 上课 | 双击 `index.html` → 按 `F` 全屏 → `→` 翻页 |
| 投影仪（浅色环境） | 按 `T` 切浅色主题，或直接打开 `index.html?theme=light` |
| 打印成 PDF | 浏览器 `Ctrl+P` → 目标选「另存为 PDF」→ 勾选「背景图形」 |
| 发给学员 | 整个 `web/` 目录打包发过去即可，纯静态无依赖 |

## 三、每页结构

沿用课件的六段式，与 `../C语言极简开发入门-课件.md` 完全一致：

| 段落 | 位置 | 说明 |
| :- | :- | :- |
| 目标 | 页头右侧 | 一句话说明这页解决什么问题 |
| 要点 | 左侧上部 | ≤ 5 条 |
| 代码 | 右侧主体 | 可复制、可滚动、语法高亮 |
| 开发坑点 | 左下橙框 | 每页 1 条 |
| VS Code 演示 | 左下蓝框 | 每页 1 条操作 |
| 练习 | 左下绿框 | 每页 1 题 |

代码块下方是**「实测输出」**——该程序真实运行的结果（绿色等宽字体），默认展开，方便对照讲解。

## 四、代码可信度

这批代码不是写完就算，全部经过实测：

- `code/` 下 21 个 `.c` 文件用 `gcc 13.2.0 -std=c11 -Wall -Wextra -O2` 编译**零警告**通过
- 网页里的每段代码与 `code/` 目录文件**逐字一致**（`test_content.js` 校验）
- 端到端验证：代码落盘 → 编译 → 运行 → 比对网页展示的输出（`test_e2e.js`，21/21 通过）
- 第 5 页的 `if (flag = 0)` 与第 6 页漏写 `break` **刻意保留 gcc 警告**，正是那两页要讲的坑点

## 五、自测脚本

```bash
node test_web.js       # 渲染 22 页、零错误、每页结构完整
node test_content.js   # 网页代码与 code/ 目录逐字一致
node test_e2e.js       # 端到端：编译 + 运行 + 输出比对（21/21）
node test_env.js       # 环境搭建页六步结构与关键内容
node test_2col.js      # 附录双栏行号与复制功能
node test_interact.js  # 讲稿 / 目录 / 主题 / 边界翻页
```

## 六、相对 PPTX 的优势

1. **代码是活的** —— 可复制到学员机器直接编译，不是静态图片
2. **实测输出内置** —— 学员看到的输出就是真跑出来的
3. **讲稿模式** —— 讲师提示不占正文画面，按 `N` 调出
4. **双主题** —— 投影用浅色、录屏用深色，一份内容两套外观
5. **零依赖** —— 没有 Office、没有网络、文件小、秒开
6. **可深链** —— `#12` 直达第 12 页，方便课堂上引用某一页
